# 真果鉴 TV 0.8.6 稳定版流程与回归清单

本清单是 TV 版的发布门禁。0.8.6 之后任何涉及首页、焦点、播放器、站源、搜索、详情、网络恢复的改动，都必须至少跑完对应自动化用例，并按本清单做一次真机遥控回归。

## 1. TV 总体流程

1. 启动：Android TV 自动识别；识别失败可在「更多 → 界面模式」手动切到电视模式。
2. 首页：默认焦点落在「开始刷剧」，方向键可遍历搜索、浏览、继续观看、热门与分类海报。
3. 焦点可见性：海报焦点是**四角标记**，按钮/胶囊是紧贴内容的描边 + 填充；
   任何位置的焦点样式都必须完整可见，不得被列表视口、封面圆角或弹窗滚动区裁掉一半
   （重点看首尾海报、热门搜索最后一个词、站源弹窗最后一行）。
4. 站源：站源入口可聚焦；选择弹窗支持清空、勾选、确定；切源期间必须显示明确加载状态，失败可重试。
5. 搜索：电视屏幕键盘和系统输入法都可用；中文、完整拼音、首字母和子序列拼音统一走同一搜索逻辑。
6. 详情：海报 → 详情 → 选集 → 播放；返回后焦点回到原海报，不得跳回页面顶部。
7. 播放：进入后视频铺满 TV 内容区，不使用全局 overscan 裁切播放器；播放层和菜单层各自管理焦点。
8. 返回：按「弹层 → 控件 → 播放页确认 → 上一级页面」逐层消费，禁止穿透。
   在发现 / 追剧 / 最近观看按返回回到首页时，左侧菜单焦点必须一起回到「首页」，
   且紧随其后的重复按键事件不得触发「再按一次退出」。

## 2. 播放页遥控器状态机

### 播放画面获得焦点时

- OK 短按：播放/暂停一次，并显示控件、把焦点交给播放按钮。
- OK 长按：350ms 后进入 3 倍速；松开恢复原倍速，不再额外触发播放/暂停。
- 左/右：快退/快进 10 秒；按住重复事件每次 5 秒。
- 上/下：
  - 刷剧模式：上一部/下一部；
  - 单剧模式或「连播本剧」：上一集/下一集。
- 菜单键：打开「播放设置」。
- 返回：控件可见时先收起控件；再次返回才弹退出播放确认。

### 控件获得焦点时

- 左/右：在底部一行控件（播放 / 倍速 / 清晰度 / 选集 / 追剧 / 连播）之间移动。
- 上/下：**仍然是上一集 / 下一集**（0.8.9）。控件层就地截获这两个键，
  不得退化成"在控件之间跳"然后表现为按了没反应。
- OK 执行当前按钮；在播放按钮上恢复播放后，焦点还给播放画面，控件四秒后自动收起。
- 返回收起控件并把焦点还给播放画面。
- 没有独立“菜单键”的精简遥控器，也能通过“短按 OK → 控件焦点”进入所有常用功能。
- 电视没有全屏 / 退出全屏按钮（电视本身就是全屏）。

### 播放设置

统一提供：选集、倍速、清晰度、连播模式、追剧、剧集详情；局域网推送可用时再显示「推送播放」。

## 3. 异常与弱网

- 首帧未到：持续显示“正在加载视频…”，不得纯黑无反馈。
- 长时间不起播/播放中断：健康检查自动恢复；失败次数耗尽后显示明确错误和「重试」。
- TV 错误页：OK 可直接重试，不能把焦点留在不可操作的播放按钮上。
- 硬解连续失败：按既有兼容策略降级软件解码一次，不能无限重试。
- 站源动态镜像：记忆成功地址 → 在线镜像 → 内置地址；在线清单不可用时必须能回落到内置地址。

## 4. 发布自动化门禁

必须通过：

- `python3 -m unittest scripts.test_app_build -v`
- Go 镜像路由无网络回归测试 + bridge 编译检查
- `flutter analyze --no-fatal-infos`
- `flutter test test/pinyin_test.dart`
- `flutter test test/television_test.dart`
- `flutter test test/tv_player_remote_test.dart`
- 发布门禁对比原始 0.8.6 全量失败基线，禁止稳定化新增失败；长期 CI 中旧全量测试保留为诊断项。TV 专项始终以 `ALL_SOURCES=true` 阻断验证正式发布形态
- TV arm64 / armv7 / all APK 真构建
- `apksigner verify`
- APK ABI / 核心 native so 完整性检查

## 5. 真机最终验收

至少使用一台 arm64 TV/盒子；如有条件再补一台 armeabi-v7a 老盒子：

- 冷启动、自动 TV 识别、手动 TV 模式切换；
- 首页全路径焦点无丢失、无死角、无不可见焦点；
- 搜索、站源切换、详情、100+ 集长剧选集滚动；
- OK 短按、OK 长按、方向键、菜单键、返回键连续操作；
- 控件/菜单/选集/退出确认连续打开关闭 20 次不丢焦点；
- 弱网、断网恢复、播放地址失败、重试；
- 自动连播下一集/下一部至少连续 10 次；
- 应用退后台再回来，播放状态与焦点正常；
- arm64/all 包均可安装，覆盖安装需签名一致。
